# 备份设置修订 · 2026-10-23

版本 0.20.1，本地修订 `2026-10-23-backup-connection`。

- 默认备份不展示可编辑地址，也不需要自动建仓勾选；首次同步才创建或复用当前账号的 dsh-sync 私有仓库。
- 连接后仅显示状态、GitHub 查看链接及「更换备份仓库」。自定义地址只在主动更换时显示，取消丢弃草稿。
- 自定义地址通过 GitHub CLI 检查可访问、PRIVATE 与 WRITE / MAINTAIN / ADMIN 权限；失败或返回不完整时保留原配置。保存不创建仓库或传输数据。
- 更换期间目标或同步状态发生变化时拒绝写入；配置写入保留其他偏好。空地址恢复默认建仓配置。
- 所有复选框均使用同步内容的同一种样式；地址管理不再使用独立复选框。输入框与选择框统一边框、圆角及 DeepSeek 蓝聚焦色，操作按钮沿用 DeepSeek 蓝。

范围：不变更当前个人备份地址，不创建或切换真实仓库。旧通用配置接口保留离线兼容，联网验证位于新增的连接保存接口；每轮同步仍重新检查仓库私有状态。没有将本次设置修订视为两台物理电脑同步验收。
