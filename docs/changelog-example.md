# 0.20.0 更新日志表达示例

以下根据已发布的 0.20.0 日志改写，用于后续写作参考；未替换历史 CHANGELOG 或 GitHub Release，也不包含发布后尚未发布的 README 修改。

## 0.20.0 · 2026-10-02

这次更新重点是让首次同步更好上手，并在需要刷新会话列表时更稳妥地重启。

- **从第一次同步到换机验证，按四步完成。** 设置页依次引导连接仓库、选择内容、开始同步和换机验收，保存后带到下一步。明确区分本地快照、同步失败和本机同步成功，提示何时还需要去另一台电脑验证。
- **需要刷新会话分组时，默认自动重启。** 等全部同步成功后才执行；会话正在生成或无法确认活动状态时，改为提示手动重启。提示会列出可能被打断的会话，可选择立即重启或稍后处理。
- **减少容易误解的提示和操作。** 不再把从未开始聊天的空白会话计为「未分组」；旧冲突副本收进折叠的只读区域；移除插件里的归档管理入口，归档改用 DSH 自身功能。
- **其他改进。** 补齐桌面安装与换机说明，明确关闭项目文件同步会同时暂停上传和取回，以及冲突时原件的保留方式。

**升级注意：** Web 与桌面端分别更新并重新打开 DSH。此前未明确关闭自动重启的用户，升级后默认启用；可在「高级：会话分组修复」关闭。自动同步仍默认关闭。

**验证：** 自动测试、本地多副本双向同步和 DSH Web 测试环境检查通过；尚未完成两台物理电脑通过 GitHub 的实网验收，也未完成实际设置页布局的目视验收。[详细记录](release-0.20.0-validation.md)
