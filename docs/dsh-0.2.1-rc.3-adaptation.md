## 已落实的行为

| 场景 | 适配结果 |
| --- | --- |
| 当前设置 | 全局 `cordis.patch.yml` 和 `profiles/<环境>/cordis.patch.yml` 都经过字段投影与本机字段恢复；不再只处理旧 `settings.yaml`。 |
| 字体与显示 | 保留主题、正文/代码/终端字体与字号、工作步骤显示及收起时机等共享字段。 |
| 模型与网页搜索 | 保留模型列表、推理参数、搜索/抓取提供方选择、普通服务地址、结果数及凭据引用名；实际凭据留本机。 |
| 本机字段 | 密钥、代理、环境映射、认证请求头、设备、本机命令和目录不进入新投影；本机已存在的对应字段按稳定身份还原。仅本机提供方被显式删除时不重建它，完整原件留在导入备份。 |
| 同步插件自身 | 当前配置条目的连接、启停和自动同步配置按本机保留，防止另一台电脑的偏好覆盖本机选择。 |
| 已有传输副本 | 本机源文件哈希未变也重新投影已有配置；旧版已跟踪的本机排除文件从新快照移出，保留本机原件及旧历史。 |
| 设置迁移 | `settings.yaml.imported`、`.env` 及本机变体排除；有迁移原件标志的目录不再导入/导出旧 `settings.yaml`，防止再次触发旧设置导入。 |
| 配置冲突 | Cordis 配置是有顺序的补丁程序；发生冲突时保留完整一侧，另一侧留在恢复记录与历史，不再用普通数组并集合并。 |
| 会话状态 | 通过官方 rc.3 编解码器校验工作目录事件、带 ignorable 标志的插件状态记录和分叉边界，保留其序号与原数据。 |
| 选择本机项目恢复 | 源会话有工作目录切换记录且最后目录不同于所选本机项目时，在新分叉的种子边界后追加本机目录事件；不改原事件，追加内容随导入计划固定，重复导入不重复追加。普通同步不重写历史目录。 |
| 草稿与登录 | 未发送草稿及视图选择属于浏览器 localStorage；窗口、浏览器存储和登录凭据不属于跨机同步内容。 |

`!!js` 动态表达式、YAML 锚点、损坏结构，以及含本机字段但缺少唯一身份的列表会暂停当前同步并指出配置文件；不执行表达式，不降级为直接上传。关闭「设置」后可继续传输其他已选内容。本机没有相应密钥、命令或路径时，仍需在目标电脑完成配置；插件清单同步不等于依赖已经安装。

本次新增排除仅作用于后续快照，不改写 Git 历史，也不自动回收同步副本、备份或历史大文件。
