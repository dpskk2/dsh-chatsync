# DSH rc.3 设置同步适配

2026-10-24：0.20.3 本地版基于适配分支 c776e29 整合，并按用户确认的范围修正。开发依赖固定为官方会话格式目录 0.2.1-rc.3，无新增运行时安装依赖。

- 适配实际 profile 与全局 Cordis 配置，保留有顺序的补丁列表。
- 自动同步等普通偏好参与同步；仅沿用既有密钥、代理和本机路径字段规则。同步页保存的偏好单独投影，连接信息继续保留本机值。

详细范围见[同步内容](sync-content.md)，本轮完整验证和实际安装情况见[0.20.3 本地记录](https://github.com/dpskk2/dsh-chatsync/blob/v0.20.3/docs/local-0.20.3-validation.md)。分支此前在其他环境的结果不作为本次本机通过证据。
