# 安装与日常使用

本版最低支持 DSH **0.2.0-rc.1**，桌面端推荐 **0.2.1-rc.2 或更新版**；独立运行使用 Node.js 24 或更新版。这是本版验证范围的支持下限，不代表侧边栏接口从该版本才出现。插件管理 → 添加插件输入 **chatsync**；旧包名 **@dpskk2/dsh-chatsync** 继续提供同版本，已安装用户可沿用原包名。

**0.20.1** 从 [GitHub Release](https://github.com/dpskk2/dsh-chatsync/releases/tag/v0.20.1) 下载 tgz 安装包和源码 ZIP。npm 同步发布同版本。物理双机验收未通过（未执行），本次按用户决定先发布。Web 与 Desktop 分别安装并重新打开。

## 1. 安装本地包

先解压完整源码 ZIP，把同批提供的 `dpskk2-dsh-chatsync-0.20.1.tgz` 放到源码目录的 `outputs/` 下。桌面端可在源码目录打开 PowerShell，运行随源码提供的备份安装脚本：

```powershell
.\scripts\install-local-desktop.ps1 -PackagePath .\outputs\dpskk2-dsh-chatsync-0.20.1.tgz -OutputDirectory .\outputs\install-0.20.1
```

安装记录目录必须是新的，避免覆盖回滚材料。脚本使用 Desktop 自带的 DSH 命令，只安装包并核对版本；安装后从菜单完全退出桌面应用，再重新打开，以加载新源码。

Web 端在同一位置安装本地包：

```powershell
dsh plugin --profile web add "file:./outputs/dpskk2-dsh-chatsync-0.20.1.tgz"
```

然后重新启动 Web 宿主。仅命令退出成功不等于正在运行的宿主已经加载新版本；可在同步状态接口或更新信息中核对 `currentVersion`，并检查实际宿主类型与状态。

## 2. 第一次设置

点击侧边栏「同步」，也可进入「设置 → 同步」：

1. **备份地址。** 安装 Git 和 GitHub CLI，运行 `gh auth login --hostname github.com --git-protocol https --web`，在浏览器完成授权。点击「使用默认备份并继续」；首次点击「立即同步」才创建或复用当前账号的 dsh-sync 私有仓库。第二台电脑登录同一账号即可复用，使用其他仓库时，点击「使用其他仓库」，填写已有私有仓库地址；保存时检查私有状态和当前账号的写入权限。连接后隐藏地址输入框，需要修改时点击「更换备份仓库」。
2. **选择内容。** 会话、聊天附件、可共享设置、项目文件分别选择，修改即时保存。首次连接默认开启自动同步（启动取回、退出上传）；已有明确开关保留。
3. **首次同步。** 点击「立即同步」。如有预览，核对范围和配置变化后「确认并继续」。等待完成，失败时查看实际错误重试。

未连接仓库时不会在启动或退出自动建仓；使用默认备份时，手动同步会自动创建或复用私有仓库。只生成本地快照不等于已经上传。

## 3. 日常使用

设置完成后直接进入「日常同步」，状态和按钮位于最上方。「同步设置」与「备份地址管理」常驻显示。默认使用 main 分支；界面无需填写，已有自定义分支保留，可在配置文件中调整。

自动同步只有启动和正常退出两个时机。总开关关闭仍可手动同步；启动失败可重试或本次离线。桌面端需从菜单完全退出，关闭窗口到托盘不会触发退出上传。断网、强退和立即关机可能无法完成上传。

同步期间可查看当前步骤；失败后根据提示检查并重试。

## 4. 换台电脑接着使用

在另一台电脑安装同一批包，连接同一个私有仓库，取回后打开已有会话、附件和项目文件检查。再新增一句对话并同步，回原电脑取回核对。

API 密钥、插件及项目依赖需在各电脑单独配置。

## 需要找回内容时

展开「查看冲突内容」，选择文件并点击「查看内容」对比双方原件。项目文件可在对比窗口底部恢复，会话分叉可另存为独立会话。历史数据问题使用独立的「检查与修复历史数据」，详见[配置与恢复](configuration.md)。
