# 0.21.0 验证范围

发布日期：2026-10-29。构建：2026-10-29-release-0.21.0。逐项结果、命令、环境与哈希见 [发布证据](https://github.com/dpskk2/dsh-chatsync/blob/v0.21.0/release-evidence/0.21.0/manifest.json)。

## 必过项

- **完整回归。** 冻结后的发布源码在 Windows 11 上分别用独立 Node.js 24 和 DSH Desktop 内置的 Electron 44.7 / Node.js 24.21 运行完整测试，要求 0 失败、0 取消；Windows 图形界面用例只在桌面端内置运行时执行，独立 Node 的那一项跳过由桌面端结果补齐。
- **候选包隔离宿主检查。** 把实际发布的安装包（含短包名 `chatsync`）装入隔离的桌面宿主，核对加载的文件哈希、版本与构建，通过公开接口读写并冷启动后读回；不使用维护者的日常数据。
- **物理双机验收（未验证）。** 本版没有两台物理电脑经专用 GitHub 私有仓库往返的证据。维护者于 2026-10-29 决定以未验证状态发布，该决定绑定本版源码指纹与安装包哈希，记录在发布证据的 `ownerDecision` 中。

## 本机验收

候选包安装到维护者本机 DSH 桌面端，由维护者目视验收同步页「同步仓库与本机存储」，包括本版新增的「本机另存旧历史」与「回收本机空间」。目视验收不是故障注入或双机验收。

## 验证边界

完整故障注入矩阵、恢复演练和物理双机 GitHub 往返均未验证。Issue #10 的原会话 ID 跨目录直接打开仍未实现：DSH 当前公开接口只提供不可变会话头和追加写入，当前恢复方案会创建新会话。已有完整 Git 传输副本只能回收 GitHub 能证明仍保有的本机旧备份引用，没有通用的原位瘦身；不能证明已在 GitHub 保留的历史继续保留。
