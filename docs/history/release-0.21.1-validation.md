# 0.21.1 验证范围

发布日期：2026-10-30。构建：2026-10-30-release-0.21.1。逐项结果、命令、环境与哈希见 [发布证据](https://github.com/dpskk2/dsh-chatsync/blob/v0.21.1/release-evidence/0.21.1/manifest.json)。

本版改动：同步仓库可以使用 GitHub 以外的 Git 托管站（[#12](https://github.com/dpskk2/dsh-chatsync/issues/12)）。

## 必过项（补丁版）

- **完整回归。** 冻结后的发布源码在 Windows 11 上分别用独立 Node.js 24 和 DSH Desktop 内置的 Electron / Node.js 运行完整测试，要求 0 失败、0 取消、0 跳过（Windows 图形界面用例由桌面端内置运行时执行）。
- **候选包隔离宿主检查。** 把实际发布的安装包（含短包名 `chatsync`）装入隔离的桌面宿主，核对加载的文件哈希、版本与构建，通过公开接口读写并冷启动后读回；不使用维护者的日常数据。

## 与本版改动相关的检查

- **地址解析。** 自动测试覆盖 GitHub、Gitee、自建 GitLab（含端口与多级组）的 HTTPS 与 SSH 地址；明文 HTTP、带令牌或密码的地址、本地路径、GitHub 的多余路径段都被拒绝。
- **私有状态检查。** 用真实 Git 对本机临时 HTTP 服务测试三种回答：要求登录（401）判为私有；无需登录可读判为公开并拒绝上传；找不到仓库或连不上判为无法确认并停止。测试中全局配置了凭据助手和认证请求头，并核对服务器收到的匿名检查请求都不带凭据。
- **托管站的匿名回答。** 2026-10-30 在本机对 gitee.com、gitlab.com、github.com 上不存在的仓库做匿名读取，三者都要求登录（401）；codeberg.org 回答找不到（404），按本版规则会停止并提示无法确认。这只说明各站对匿名请求的回答方式，不是用真实私有仓库完成的同步。
- **保存与上传闸门。** 自动测试覆盖：公开、网络失败、SSH 密钥未配置、仓库不存在、超时时保存失败且原配置逐字节不变；公开的非 GitHub 仓库在建立同步副本前停止；非 GitHub 地址的私有检查和保存不调用 GitHub CLI。
- **真实 GitHub → Gitee 端到端。** 2026-10-30 在一台 Windows 11 电脑上启动两个隔离的已安装桌面宿主（DSH 0.2.1-rc.3），使用合成会话和附件，以及专用的 GitHub 私有测试仓库和两个 Gitee 私有空仓库；私有检查不做任何替换，Gitee 登录由维护者按新的登录帮助在终端完成一次。
  - 两台宿主先经 GitHub 互相取回会话和附件。
  - 通过同步页使用的连接接口填写 Gitee 上的公开仓库，被拒绝并提示「公开仓库」，配置不变。
  - 只带当前内容：A、B 先后改到空的 Gitee 仓库并同步，四个会话和附件两边一致，Gitee 上是核对过的提交，GitHub 仓库不再变化。
  - 复制全部分支：用 `git clone --bare` 和 `push refs/heads/*` 把 GitHub 仓库复制到第二个空的 Gitee 仓库，两台宿主改地址后继续同步，五个会话一致，复制过去的分支都保留。
  - 在内置浏览器中打开隔离宿主的真实同步页：显示「已连接同步仓库」和「在 Gitee 查看仓库」；点「立即同步」成功；在表单中填 Gitee 的 SSH 地址时（本机没有 SSH 密钥）提示先配置 SSH 密钥且原地址不变；改填 HTTPS 地址保存后再点「立即同步」，提交并上传到 Gitee。
- **更换托管站（自动测试）。** 用两个本地裸仓库代表两个站点、两台模拟电脑：把旧仓库全部分支复制到新仓库后两台电脑先后改地址，继续同步并取回新增内容，旧仓库不再写入；改到空仓库时只上传这台电脑的当前内容，旧仓库独有的分支留在旧仓库。

## 本机验收

候选包安装到维护者本机 DSH 桌面端，由维护者目视验收同步页的同步仓库设置：自定义地址说明、登录帮助，以及已连接仓库的查看链接。目视验收不是故障注入或双机验收。

## 验证边界

- Gitee 端到端在同一台电脑的两个隔离宿主上完成，不是两台物理电脑；没有用真实的 GitLab 或自建站验证，也没有验证 Gitee 的 SSH 地址成功同步（只验证了未配置密钥时的提示）。
- 匿名检查只能区分「任何人可读」和「需要登录」，不能识别 GitLab 等的「内部」可见性；SSH 地址借用同一站点、同一路径的 HTTPS 地址检查，网页地址不同或部署在子路径下的站点会停止同步。
- 完整故障注入矩阵与恢复演练未在本版执行。
