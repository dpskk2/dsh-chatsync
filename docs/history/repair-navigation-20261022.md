# 未分组会话的处理引导

本地构建：`2026-10-22-repair-navigation`，版本 0.20.1。

## 用户看到什么

发现未分组会话时，提醒只显示数量与「去处理」「稍后处理」两个按钮，不解释内部登记，也不在弹窗内折叠处理工具。

点击「去处理」进入独立的「处理未分组会话」页面。页面自动读取当前未分组会话，直接显示会话名称、原项目文件夹与「查看处理方案」。选中会话后查看说明、选择本机项目，再确认恢复。原始记录位置放在每条会话的「查看记录位置」中。

同步设置中的「处理未分组会话」也直接打开该页面。「会话与数据修复」用于更广泛的数据检查、处理修复安排和核对结果、查看修复备份。它是独立页面，主要工具直接显示。

打开提醒和处理页面只读取本机状态，不上传，不确认修复，也不关闭应用。恢复操作仍需明确选择项目并确认；原件校验、活动会话保护和失败接续保留。
