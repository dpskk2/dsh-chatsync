- 实际桌面宿主为 DSH 0.2.1-rc.3，Electron 44.7.0 / Node.js 24.21.0；只读取其安装代码，真实宿主检查使用独立合成数据。
- 同时核对上游 `f3803c96974ad4a94195fb97e5c637e9c2a3afe3`（0.2.2-alpha.2）的[会话持久化接口](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/session/session-persistence/src/index.ts)和[工作区登记](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/workspace/workspace/src/index.ts)。这只是相关源码审阅，不是 alpha.2 宿主兼容验收。
- 会话头中的 cwd 不可变，持久化接口提供 create/open/append/flush/stat/list，没有原身份重定位能力。工作区挂接还会校验会话原始 cwd 与实际项目路径一致。因此不通过重写日志、修改宿主私有缓存或伪造路径来实现 #10。

## 本轮修正

1. [会话恢复候选](../../lib/session-recovery.js)返回项目路径；[迁移预览](../../lib/session-relocation.js)据此预选唯一匹配的项目。已明确清理的旧恢复记录不再让后续预览因悬空索引永久失败；重新预览会重新保存当前原件。
2. [本机存储检查](../../lib/local-storage.js)只在宿主导入已验证、原会话归档、原件哈希与身份一致且已移入历史记录时，释放迁移预览索引对恢复原件的引用。待处理导入、其他引用、保留时间和逐项确认继续生效。
3. 旧主 Git 仓库不能仅凭远端地址相同获准清理；必须没有未提交改动，分支、标签和 reflog 中的提交也都被当前副本覆盖。其他旧同步副本同样检查 stash、其他引用与 reflog 的独有提交。
4. [本机候选检查](../../scripts/check-local-package-desktop.mjs)使用实际源码字节指纹，覆盖未暂存与新增文件，另核对运行代码和语言文件。正式发布门禁仍要求已提交且冻结的源码；没有放宽门禁。
5. 开发依赖的 Zod 固定到已修补的 4.6.6，保留官方 DSH 格式校验包版本，没有增加运行时依赖。重新安装锁定依赖后审计为 0 漏洞。
6. 0.21.0 尚未发布，移除日志中无证据的物理双机通过表述，纠正仍指向 0.20.1 的安装说明。旧候选的验证证据不能自动用于当前构建。
7. [原生会话安全检查](../../scripts/check-issue4-safe.mjs)按当前 DSH 的具名插件导出加载持久化服务并等待其就绪，修正旧脚本无法启动独立租约检查的问题；没有修改宿主代码。
