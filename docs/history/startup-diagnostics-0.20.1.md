# 启动问题定位与误报修复 · 2026-10-21

## 本机问题

本次失败来自 chatsync 工作区，其他两个工作区已同步。原报告包含 4 个测试文件命中：测试用密码、私钥标题和明确 test-only 占位值。对同一个待上传提交重新进行只读检查，113 个内容对象、1500342 字节全部扫描，原 4 处误报归零；检查没有上传、重写历史或删除文件。

## 修改

- 测试源码中的明确 fixture / test-only 等占位文本，以及不含正文的独立引号私钥标题，不再当作真实密钥。测试文件中的完整令牌、私钥正文和普通凭据仍检查；普通文件不使用测试样例例外。
- 问题报告保留所属工作区、文件、命中行号，超过上限时显示文件大小和检查上限；报告不包含命中的密钥值。多个工作区同时失败时保留各自报告。
- 启动弹窗及日常同步页直接列出“问题详情”。文件位置可展开、复制；“查看技术记录”在同一处展开，无须先离开弹窗寻找详情。
- 删除“完成后进入 DSH；也可以先离线使用”等重复说明，保留实际任务、进度和操作按钮。
- 本地打包从 Git 已登记的源码复制到隔离的打包目录，再生成安装包。OneDrive 重新带回的电脑名副本保留在原位置，不混入安装包。新源码文件应先登记到 Git，可使用 intent-to-add 保留未提交状态。打包脚本为 scripts/pack-local.ps1。
