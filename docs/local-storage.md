# 本地存储与备份

在「同步」页面选择「本地存储与备份 → 查看占用并清理」。检查只读取本地材料，不连接同步仓库。

- 按恢复与冲突备份、会话应用种子、配置历史、修复原件与预览、同步仓库和项目旁备份分类，显示路径、逻辑大小、用途与保留原因。
- 默认保留最近 30 天，可选 7、90、180、365 天或不按时间保留；只影响本机清理筛选，每次由用户选择、预览并确认后执行，没有自动删除任务。
- 当前同步库、旧主库 Git 历史、旧项目 Git 库、未上传或未提交的旧同步副本，以及待导入、待修复、待核对和被依赖的材料受到保护。无法读取元数据或遇到目录联接时不清理。
- 已完成的恢复记录、无引用的应用种子、过期预览、配置历史可以选择清理。旧的干净主数据同步副本和经过归属核对的项目旁备份需要单独确认。
- 删除前重新核对全部所选材料的内容和依赖；变化时停止。逐项显示成功或失败，失败时保留尚存材料的路径。

清理会永久移除所选本地恢复来源。会话日志中的附件引用不等于附件字节，单独保存日志不能保证恢复附件。清理不会缩短当前 Git 历史，也不清理云端；云端仍保留的旧历史可能重新下载。

显示的是逻辑字节大小；硬链接、压缩和文件系统分配会影响实际释放的磁盘空间，不能将多个副本的大小简单相加认定为实际空间。当前版本不做跨备份正文去重或远端历史瘦身。
