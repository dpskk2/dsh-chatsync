# 本机备份

（改动）在「同步」页面的「同步仓库与本机存储」点击「检查」，「本机备份」一行显示总大小和可删除的大小，点「清理」打开明细。检查只读取这台电脑上的材料，不连接同步仓库。

- 按恢复与冲突备份、会话应用种子、配置历史、修复原件与预览、同步仓库和项目旁备份分组，每组默认折叠，显示大小和用途；展开后每项显示路径、大小，受保护的项显示保留原因。
- 默认保留最近 30 天，可选 7、90、180、365 天或不按时间保留。保留期内的备份不能选择；删除只在你选择、预览并确认后进行。
- 当前同步库、旧主库 Git 历史、旧项目 Git 库、未上传或未提交的旧同步副本，以及待导入、待修复、待核对和被依赖的材料受保护，不能选择。元数据读不出来或遇到目录联接时，相关材料同样受保护。
- 已完成的恢复记录、无引用的应用种子、过期预览、配置历史可以选择删除。旧的干净主数据同步副本和经过归属核对的项目旁备份，在确认页还要单独勾选一次。
- 点「删除…」先显示要删除的清单和总大小，点「永久删除」后重新核对全部所选材料的内容和依赖，有变化就停止。结果逐项显示，失败的项会写明仍在的位置。

删除后不能再从这些备份找回旧版本。会话日志里的附件引用不包含附件本身，只留日志不能找回附件。删除本机备份不影响同步仓库；同步仓库的占用见「同步仓库与本机存储 → 同步仓库」。

大小按文件本身计算；与其他备份共用（硬链接）的文件，删除后实际腾出的空间会更少，多个副本的大小不能直接相加。
