# 0.12.12 兼容验证记录

日期：2026-09-29。实际环境：Windows 11、Node.js 24.19.0、DSH 0.2.0-rc.1。

## 已完成的检查

- `npm test`：34 项测试及补丁脚本 8 项计数检查通过。覆盖真实本地 Git 远端、两个独立数据目录的 A 上传 → B 取回 → B 新增 → A 取回、工作区恢复、凭据排除与故障重试。
- 新增会话分叉测试：两端修改同一个纯文本日志的不同位置，确认不会经 Git 拼接；双方原件提交仍可读取，远端备份分支上传成功，下一轮同步收敛到保留的一侧。
- 新增追加历史、重叠编号、种子重写、头版本不一致、损坏行、zstd 串联帧、截断帧和正文包含魔数字节的回归检查。
- `scripts/check-dsh-host.mjs`：两个临时 DSH 数据目录实际启动 0.2.0-rc.1；插件加载、状态接口、切换自动模式、停止后重新启动并保持模式均通过。未使用用户配置、模型凭据或外部同步远端。
- `scripts/check-dsh-sessions.mjs`：对本机 10 个会话的当前日志执行只读检查，6 个 v4 用当前校验器、4 个 v3 用历史校验器，通过；并确认追加历史选择返回原始字节。没有改写会话。v3 校验不等同于完成需要子会话证据的 v3 → v4 迁移。
- 网页抓取补丁审核：npm 官方 `@deepseek-ai/dsh-web-fetch-http@0.2.0-rc.1` 原始目标文件与本机补丁的原始备份一致，可继续套用原补丁；此结论不是全网络环境的抓取测试。

## 边界

隔离的 Git 双副本测试与两个真实 DSH 宿主加载测试分别完成，不声称已在两台物理电脑进行实网端到端验收。DSH 正式版 0.2.0 和其他操作系统的实际宿主未在本次本机测试覆盖。

会话分叉采用保留一侧、保存双方历史并提示恢复位置的策略，不再承诺将两个独立执行流合成一个可继续执行的会话。未来版本的文件名可被识别，不代表已经验证未来格式的全部语义。

用户的两个旧会话补丁只针对本机已审核的 0.2.0-rc.1 标记停用，旧版本机器仍保留原清单适用逻辑。这些用户补丁不随插件源码或 npm 包发布。

压缩帧长度检查依据 [Zstandard 官方格式说明](https://github.com/facebook/zstd/blob/dev/doc/zstd_compression_format.md)，解压仍使用 Node.js 内置实现。

## 可复现命令

普通回归：`npm test`、`npm pack --dry-run`。

安装 DSH 后可运行额外只读 / 隔离检查（两个参数均为绝对目录）：

```text
node scripts/check-dsh-host.mjs <DSH安装包目录>
node scripts/check-dsh-sessions.mjs <DSH安装包目录> <DSH数据目录>
```

后一个命令只输出计数，不打印聊天正文；前一个命令保留临时测试目录供检查。
