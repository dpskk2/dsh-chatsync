# 0.20.1 发布验证 · 2026-10-23

本版最低支持 DSH **0.2.0-rc.1**，桌面端推荐 **0.2.1-rc.2 或更新版**；独立运行使用 Node.js 24 或更新版。这是本版验证范围的支持下限，不代表侧边栏接口从该版本才出现。插件管理 → 添加插件输入 **chatsync**；旧包名 **@dpskk2/dsh-chatsync** 继续提供同版本，已安装用户可沿用原包名。

本版包含会话安全应用与修复、范围与隐私保护、正常未分组与归档语义、同步设置及旋转图标修正。当前声明针对 Windows 本机检查，完整环境和逐场景结果见 [发布证据](https://github.com/dpskk2/dsh-chatsync/blob/v0.20.1/release-evidence/0.20.1/release-review.md)。

## 发布决定和边界


本次 0.20.1 例外：用户明确要求“我暂时不希望做这个事情，可以登记为物理双机验收未通过。你理论上检查没问题就先发版”。允许在源码审查、自动回归、实际候选包核对无阻断问题后，依据绑定源码和包哈希的 ownerDecision 先发布。物理双机未通过（未执行）及尚未完整覆盖的故障、真实宿主和恢复场景保留 not-verified，必须公开说明；实际 failed、缺失检查、过期指纹或证据损坏仍阻断。默认完整验收规则不变。


源码审查和自动检查结论仅适用于记录的源码及安装包。未发现阻断问题不代表所有设备、网络、历史格式或进程交错均安全。未知输入应停止并保留原件。正常退出上传与强退、关机、托盘不同。

## 已检查与尚未完成

- 完整自动回归与补丁断言分别记录独立 Node、Desktop 自带运行时、终态退出码及失败/取消/跳过数。
- 实际候选包在隔离位置安装，真实 Desktop Host 公开写入、读回并重启核对，记录包和载入文件哈希。隔离宿主不是日常窗口验收。
- 本地 Git 故障用例与真实宿主修复只代表覆盖的合成数据场景；完整清单中的存储故障、全生命周期、混合版本和全部 Desktop 恢复交互未全部覆盖。
- **物理双机验收未通过（未执行）**。没有将同机双副本或本地 Git 改称两台电脑实网验收。
- 默认完整门禁仍保留。此版使用明确的 ownerDecision 记录接受哪些未验证项，实际失败不在例外之内。

## 安装和恢复

从 GitHub 下载本版 tgz 和完整源码 ZIP，按[安装指引](getting-started.md)使用本地包。更新前保留原数据和备份；修复需先预览并核对结果。安装后需核对实际版本与构建，不能把安装命令成功当成宿主已加载新包。
