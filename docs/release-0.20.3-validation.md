# 0.20.3 发布构建验证范围

日期：2026-10-25。构建：2026-10-25-release-0.20.3。

本版包含本地存储与备份清理、指定可安装版本的更新提醒与命令、新配置默认启动/退出自动同步，以及 DSH 0.2.1-rc.3 设置同步适配。源码维护、候选包和原始报告仍统一归档于维护目录；GitHub 与 npm 使用同一冻结源码，两种安装名称只转换必要的包身份。

## 证据核对

发布构建单独冻结源码、生成候选包并执行验证。开发阶段的结果保留在[本地验证记录](local-0.20.3-validation.md)，不能直接代替发布构建的证据。发布构建的逐项状态、源码指纹、安装包 SHA-256、原始终态和审查记录见[本版证据目录](https://github.com/dpskk2/dsh-chatsync/tree/v0.20.3/release-evidence/0.20.3)。只有实际完成的范围可以记录为通过。

回归分别使用独立 Node 与桌面内置 Electron/Node；候选包检查使用隔离的真实 DSH Desktop Host，核对加载版本和运行文件，并经公开接口清理合成备份、核对原件及冷启动读回。内置 Node 回归、隔离 Host 和实际 Desktop 窗口是不同的验证层次。

## 验证边界

物理双机经专用 GitHub 仓库实网往返、完整 Desktop 窗口操作、完整故障注入与灾难恢复矩阵尚未完成。同机双副本、本地 Git、自动化接口检查均不能代替这些验收；保留未验证状态，不宣称全部安全门禁项目均已实测通过。发布授权与允许未验证场景发布的决定是不同条件，不能从历史版本沿用。

README 按用户要求保持 GitHub 主线原文。新配置默认值、设置同步范围和清理操作以本版更新日志、[配置参考](configuration.md)及[本地存储说明](local-storage.md)为准。清理只在预览并确认后执行，保留时间不会启动自动删除。
