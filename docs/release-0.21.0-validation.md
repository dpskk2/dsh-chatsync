# 0.21.0 验证范围

日期：2026-10-26。构建：2026-10-26-release-0.21.0。

本版包含：同步跟随 Windows 系统代理、默认备份连不上时说明原因、只同步允许清单内的内容、设置补丁按条目合并、DSH 版本不同时暂停设置同步、清理远端残留的本机文件、可选同步指令与技能、本机接口拒绝跨站请求、会话写入中稍后重读、导入文件原子替换，以及移除本机补丁、Web 端自动重启和 0.12 之前的迁移代码。内部把同步引擎、本机接口和界面按职责拆分，并加入格式与类型检查，这部分不改变同步行为。

0.21.0 是次版本，按[发版前数据安全检查](https://github.com/dpskk2/dsh-chatsync/blob/main/docs/release-safety-checklist.md)的分级门禁验收。逐项状态、源码指纹、安装包 SHA-256 和原始终态见[本版证据目录](https://github.com/dpskk2/dsh-chatsync/tree/v0.21.0/release-evidence/0.21.0)；只有实际完成的范围记录为通过。

## 必过项

- **完整回归。** 冻结后的发布源码在 Windows 11 上分别用独立 Node.js 24 和 DSH Desktop 内置的 Electron 44.7 / Node.js 24.21 运行完整测试，要求 0 失败、0 取消、0 跳过；Windows 图形界面用例只在桌面端内置运行时执行，因此独立 Node 的那一项跳过由桌面端结果补齐。
- **候选包隔离宿主检查。** 把实际要发布的安装包装入隔离的桌面宿主，核对加载的文件哈希、版本与构建，通过公开接口读写并冷启动后读回；不使用维护者的日常数据。
- **物理双机验收。** 维护者在两台电脑上安装最终候选，经专用的 GitHub 私有仓库完成「A 上传 → B 取回 → B 新增 → A 取回」，并在重启 DSH 后读回，由维护者确认结果。

## 验证边界

完整故障注入矩阵和恢复演练未在本版执行，按分级门禁作为参考检查保留为未验证。本版内部重构较多，同步页面没有在最终候选上逐项重新走查；页面操作只覆盖双机验收实际用到的部分。以上项目不宣称已实测通过。
