# 0.21.4 验证范围

本版修复 DSH 自定义插件管理中「同步」详情的设置开关。正式安装包检查覆盖短包名和旧作用域包名、隔离 Windows 宿主冷启动、读写及重启后读回。本版的完整自动检查覆盖独立 Node 和 Windows 桌面内置运行时。验证记录见源码仓库的 [0.21.4 发布证据](https://github.com/dpskk2/dsh-chatsync/tree/v0.21.4/release-evidence/0.21.4)。

在「插件 → 添加插件」打开已安装的「同步」详情，可检查「侧边栏显示同步」「自动同步」「自动检查更新」三个开关。关闭自动同步后，仍可以手动同步。具体的启动和退出选项在「同步设置」里继续分别保存。

本版没有执行物理双机或 macOS 桌面实际点击验收。
