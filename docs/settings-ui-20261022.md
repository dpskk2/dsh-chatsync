## 登录与自动建仓究竟何时生效

1. 安装 Git、GitHub CLI，运行：

   ```powershell
   gh auth login --hostname github.com --git-protocol https --web
   ```

   命令已指定 github.com 和 HTTPS，仍需按提示在浏览器完成账号授权。[GitHub CLI 官方说明](https://cli.github.com/manual/gh_auth_login)

2. 备份地址留空，保留自动建仓勾选，保存设置。保存只记录配置，不建仓、不上传。
3. 点击「立即同步」。插件读取当前 gh 账号，检查其 dsh-sync 仓库：私有仓库已存在就复用，不存在才创建私有仓库，并保存地址。需要当前账号具备仓库访问或创建权限，且网络可以连接 GitHub；公开仓库不会被当成备份目标上传。
4. 第二台电脑登录同一账号，同样留空地址即可复用。若原来使用其他仓库名或账号，则填写对应已有私有仓库地址。

自动建仓和自动同步是两个选项。自动同步总开关关闭时，手动点击同步仍能触发自动建仓。未连接仓库时，启动和退出不会仅因为默认勾选而自动建仓。

## 重复 wait-lock 的原因

进程锁防止两个 DSH 宿主同时改写同一份同步数据。等待期间每 250 毫秒检查一次，旧代码每次检查都写入一条阶段记录，所以同一次等待会出现很多行，不代表反复失败或多次上传。

本次保留锁与等待机制，只合并相邻相同阶段。同步页删除分阶段耗时及 Git 对象复用等细节，保留总耗时、上传/下载量、工作区结果、错误和待处理问题。
