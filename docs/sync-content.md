# 同步内容

| 类别 | 包含 | 关闭时 |
| --- | --- | --- |
| 会话 | 会话日志、项目归属和相关登记信息 | 暂停上传与取回，保留远端已有内容和本机原件。 |
| 聊天附件 | 对话中上传的图片、文件 | 暂停该类两个方向的传输。 |
| 可共享设置 | 主题、字体字号、模型、搜索与插件偏好 | 各机密钥、代理与路径始终保留；关闭后不交换设置。 |
| 项目文件 | 项目目录的代码、文档，包括生成在项目目录中的 Word / Excel | 独立开关，关闭后同时停止上传与取回。 |

项目文件沿用本机路径映射，不能指向 DSH 数据目录或与之互相包含。默认排除 Git 元数据、`node_modules`、依赖缓存；用户额外排除项保留。

本机凭据、同步连接、锁、缓存、日志、生命周期状态、临时文件、冲突原件和恢复前备份不随主数据上传。设置中的本机密钥、代理和路径按字段保留。

DSH 0.2.1-rc.3 的当前设置主要在 `profiles/<环境>/cordis.patch.yml`，数据目录下的 `cordis.patch.yml` 是更高优先级的全局覆盖；两处均按字段投影。`apiKeyEnv` 等引用名称可以同步，实际密钥需在每台电脑配置。密钥、代理、环境变量、认证请求头、本机路径、设备选择及 chatsync 自身的连接与自动同步配置各机保留。依赖本机命令或路径的插件仍需在目标电脑完成配置；同步清单不代替插件安装。

`settings.yaml.imported` 是迁移原件，仅留本机；已存在这份迁移原件时，不再取回或上传旧的 `settings.yaml`，以免重启时再次导入旧设置。旧版本尚未迁移的数据目录继续支持旧设置文件。`.env` 及其本机变体不参与同步。

Cordis 配置列表有执行顺序；发生 Git 冲突时保留完整本机版本，另一侧留在恢复记录与 Git 历史，不把配置操作当普通数组求并集。含 `!!js` 动态表达式、YAML 锚点或无法唯一识别的含本机字段列表时，暂停本次同步并说明文件；可先关闭「设置」继续同步会话与附件，不会直接复制未经投影的配置。

未发送草稿、浏览器视图选择、窗口大小和登录状态不跨机迁移。已上传到 Git 历史的旧内容不会因新增排除规则自动从历史抹除。

传输前检查未上传历史；首次、较多删除、设置或执行配置变化会要求确认。检查和确认绑定实际提交，期间内容变化需重新核对。

新会话和可确认的追加更新按宿主能力应用，运行中不直接替换原件。会话分叉分别保留，远端删除不直接删除本机日志；无法安全应用的内容保持待处理。
