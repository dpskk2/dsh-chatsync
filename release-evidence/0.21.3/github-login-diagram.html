1. 安装 Git
  2. 安装 GitHub CLI
  3. 打开“终端”（如需通过代理访问 GitHub，请确保已通过环境变量为 GitHub CLI（gh）配置可用代理，或已启用能够代理 GitHub 流量的 TUN 模式。），运行 gh auth login --hostname github.com --git-protocol https --web
  4. 根据指引完成授权（输入 Y，点击 Enter 打开授权页，输入“终端”显示的一次性代码）
